# Pacote de sons "paper-cutout"

Sons sintetizados para animação de recortes de papel, gerados de raiz neste projeto. São nossos e podem ser usados livremente.
WAV 48 kHz estéreo, normalizados a −1 dBFS de pico.

| Ficheiro | Uso |
|---|---|
| `paper_flip.wav` | Um recorte entra ou vira (160 ms) |
| `paper_slide.wav` | Papel a deslizar ou a transição de faixa (350 ms) |
| `paper_tear.wav` | Arrancar uma folha do calendário (550 ms) |
| `paper_crumple.wav` | Amarrotar papel (700 ms) |
| `scissors_snip.wav` | Corte de tesoura, para riscar ou recortar (250 ms) |
| `stamp_thud.wav` | Carimbo a bater (500 ms) |
| `pin_tack.wav` | Pionés ou um recorte a "colar" no quadro (300 ms) |
