Zinho Automação

Ferramenta interna do canal de animação "Zinho, o Sortudo".

A Zinho Automação é uma ferramenta de uso pessoal que produz os vídeos animados do canal "Zinho, o Sortudo" e os envia para o próprio canal no YouTube, através da API oficial do YouTube (YouTube Data API v3).

A ferramenta não é oferecida ao público e só é usada pelo dono do canal.
