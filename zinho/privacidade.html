Política de Privacidade

Zinho Automação · última atualização: 30 de outubro de 2026

1. Quem somos

A Zinho Automação é uma ferramenta de uso pessoal do dono do canal do YouTube "Zinho, o Sortudo", usada para publicar os vídeos do próprio canal.

2. Que dados acedemos

Com a autorização do dono do canal, a ferramenta usa a API do YouTube (escopo youtube) apenas para:

  • enviar vídeos para o canal do próprio utilizador que a autorizou;
  • definir título, descrição, tags, thumbnail e data de publicação desses vídeos.

Não lemos, recolhemos nem guardamos dados de outros utilizadores, espectadores, comentários ou mensagens.

3. Como guardamos as credenciais

O token de autorização fica guardado apenas como variável de ambiente privada no servidor do dono do canal. Não é partilhado com terceiros nem vendido.

4. Partilha de dados

Não partilhamos dados com terceiros. Os únicos serviços contactados são as APIs oficiais da Google.

O uso e a transferência de informação recebida das APIs da Google cumprem a Política de Dados do Utilizador dos Serviços de API da Google, incluindo os requisitos de Uso Limitado.

5. Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

6. Serviços do YouTube

Ao usar esta ferramenta, também se aplicam os Termos de Serviço do YouTube e a Política de Privacidade da Google.
